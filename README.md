# Daily Shorts Bot

Set `VIDEO_LANG` in `.github/workflows/daily.yml`: `hinglish`, `hi` (Hindi) or `en` (English).
Optional: `VIDEO_STYLE` (`editorial` or `full`), `MEDIA_MODE` (`photos`, `hybrid`, or `videos`), `TTS_RATE` (default `+12%`), `USE_GEMINI` (`true`/`false`), and `assets/bg_music.mp3`.
Secrets: `CLIENT_ID`, `CLIENT_SECRET`, `REFRESH_TOKEN`, `PIXABAY_API_KEY` / `PEXELS_API_KEY` (optional `GEMINI_API_KEY`).
